# One YouTube channel per line.

# Older videos can therefore be selected when they performed better.
#
# Optional settings:
#   limit=5       number of unseen winners to add
#   min_views=100000
#   scan=0        metadata scan limit; 0 means scan all channel videos
#
# Examples:
# https://www.youtube.com/@veritasium | limit=5
# @lexfridman | limit=3 | min_views=100000
