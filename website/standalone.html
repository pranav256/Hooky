Frequently Asked Questions

      


      

        

          
            Can Hooky run without a dedicated GPU?
            
          
          

            Yes. Hooky auto-detects hardware on launch. If no CUDA GPU is found, it switches whisper to compute=int8 CPU mode and runs multi-threaded CPU FFmpeg encoding.
          

        


        

          
            How does Hooky bypass YouTube rate limits and age gates?
            
          
          

            Hooky integrates browser cookie extraction via yt-dlp. Set YTDLP_COOKIES_FROM_BROWSER=chrome (or edge/brave/firefox) in your .env to inherit authenticated sessions automatically.
